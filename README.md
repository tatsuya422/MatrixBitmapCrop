# Matrix / Bitmap 斜め範囲切り出し

## 丸印のドラッグによる枠調整

①②を指定した段階から、丸印をつかんで位置を調整できます。3点で枠を確定すると四隅に丸印を表示し、角のドラッグで反対側の角を固定したまま幅と高さを変更できます。斜めの向きと実寸上の直角を保持し、数値欄・緑の保存範囲にも反映します。

丸印の操作は「枠を移動」のON/OFFにかかわらず使用できます。枠全体の移動は「枠を移動」をONにして枠内をドラッグします。移動中は四方向、角の調整中はサイズ変更のカーソルに切り替わります。反対側の角を越えるドラッグでは枠を反転させず、内側指定後もデータが残る最小サイズで止めます。

画面と処理を `MatrixBitmapCrop.Controls.dll` に分離し、起動用EXEから共通DLLを使用する構成にしました。DLLの呼び出し方、言語指定、配置方法は [DLLと多言語化.md](DLLと多言語化.md) を参照してください。翻訳表はDLLに埋め込まれます。MatrixView2Dと同じく初期言語は英語で、日本語では各Releaseフォルダーの `StartJapanese.cmd` から起動できます。

## 操作

操作欄は画面左側、画像は右側の表示領域の中央に配置しています。余白がある方向は中央に保ち、拡大して収まらない方向はスクロールできます。中央配置のまま切り出し・マスク指定を操作できます。「切り出し」タブで範囲の抽出、「マスク」タブで周囲の値による補間、「切り出し」タブ内の表示操作で拡大縮小を操作します。ウィンドウが小さい場合は左側を縦にスクロールできます。タブを切り替えても指定範囲を保持します。

## マスク補間の操作

1. 「マスク」タブの「入力フォルダーを開く」でMatrix TXTを読み込みます。BMPがある場合は参考画像として使い、BMPがない場合は最初のTXTから位置指定用の濃淡画像を自動生成します。先頭に番号があるファイルは番号順（1、2、…、10）、番号がない場合は名前順で選択します。Matrixの1セルが画像の1画素に対応します。複数のBMPの切り替えは「切り出し」タブの一覧で行います。画像やフォルダーを変更するとマスク指定はクリアされます。
2. 形状を選び、参考画像上で補間する箇所を指定します。黄色の塗りが登録済みの範囲です。
   - **矩形**：左ボタンで対角方向へドラッグします。複数箇所を続けて登録できます。
   - **多角形**：頂点を順番にクリックし「多角形を確定」を押します。斜めの輪郭や四隅の不定形なはみ出しに使います。
   - **幅付き線・溝**：線幅をmm単位で設定し、溝の中心に沿ってドラッグします。実寸ヘッダーがない場合はピクセル単位です。十字溝は縦横の線を重ねます。斜めの線にも対応します。
3. 不要な領域は一覧で選択して削除できます。右クリックまたは「描画中の指定を取り消す」で未確定の描画を取り消し、「すべてのマスクをクリア」で登録済み領域も消せます。
4. 「0を周囲の参照値から除外」は初期値ONです。0が未計測値の場合に使います。0が有効な計測値である場合はOFFにしてください。
5. 「全TXTをマスク補間して保存」を押すと、直下の全TXTをそれぞれの周囲データから補間し、`MASK_yyyy_MM_dd_HH_mm_ss` フォルダーへ元と同じファイル名で保存します。同名フォルダーがある場合は連番を付けます。処理中のファイル名と終了件数を表示します。

マスク処理は元の行列サイズとヘッダーを保持し、指定セルのみを整数の推定値に置き換えます。0点補正OFFではマスク外のセルは元の文字列を保持します。ONではマスク補間後に全セルへ最小値の差し引きを適用します。実寸モードでは各TXTの幅・高さ・行列数からマスク位置を再計算するため、行列数が異なっても同じmm位置を処理します。図形が画像やMatrixの外にはみ出した部分は適用対象から除きます。

TXTからの参考画像は0を黒、0以外を最小値～最大値に応じた濃淡で表示します。一定値の場合も見えるよう中間色で表示します。生成画像はメモリ上で使用し、入力ファイルは変更しません。処理結果フォルダーには `MaskReference.bmp` として保存されます。生成元は「切り出し」タブの参考画像欄に表示します。

複数領域は重なりを合成してから処理します。十字の交点や別のマスク領域を参照値には使いません。周囲の傾斜面を求めてから残差を滑らかに補間し、端の領域では画像内の周囲データから傾斜を延長します。参照できるデータが不足するファイルはエラーとして記録して次へ進みます。補間結果は推定値であり、隠れた形状を実測として復元するものではありません。

マスク設定はXMLで保存・再読込できます。実寸モードの設定は解像度が異なるMatrixにも同じmm位置で適用できます。旧版のピクセル座標の設定は同じ画像サイズで読み込んでください。マスク処理の保存先には次も出力します。

- `MaskDefinition.xml`：図形のmm座標・線幅、実寸幅・高さ、行列数、1画素の寸法。実寸ヘッダーがない場合は従来のピクセル座標。
- `MaskReference.bmp`：元の参考画像。
- `MaskRegions.png`：指定領域を黄色で重ねた確認画像（補間後の計測画像ではありません）。
- `MaskResult.log`：補間した画素数、設定、成功・失敗理由。実寸モードでは各TXTの実寸・行列数・1画素の寸法も記録。
- 元の名前の `.tmp` と `.3m`：入力フォルダー直下の付随ファイルのコピー。

## 実寸による画像表示とマスク座標

ヘッダーの `#WIDTH 156.8, HEIGHT 152.0` を幅156.8mm・高さ152.0mmとして読み取ります。数値データの列数・行数から次を計算し、「マスク」「切り出し」タブに表示します。

- X方向の1画素の寸法 = WIDTH ÷ Column（列数）
- Y方向の1画素の寸法 = HEIGHT ÷ Row（行数）

画像はこの実寸の縦横比で表示します。画面上の大きさはズーム倍率によって変わります。左上を(0, 0)mmとし、右方向がX、下方向がYです。マスク操作中はカーソルのmm位置を表示します。BMPがなくTXTから画像を生成する場合も同じ計算を使います。

マウス位置をmmへ変換してマスク座標を保存します。各TXTの処理では、列位置=X(mm)÷そのTXTのX画素寸法、行位置=Y(mm)÷そのTXTのY画素寸法として適用します。幅付き線もmmで指定します。参考BMPの画素数とMatrixの行列数が異なる場合も画像全体をヘッダーの実寸に対応させます。

有効なWIDTH/HEIGHTがない参考データはピクセル表示・指定に戻ります。mm座標のマスクを適用する対象TXTに有効なWIDTH/HEIGHTがない場合は、そのファイルをエラーとして記録します。切り出しの「四辺から内側へ」は引き続きピクセル単位です。

## 切り出しの操作

1. 「フォルダー指定」で元画像とMatrix TXTが入ったフォルダーを選びます。直下の `*.bmp` と `*.txt` を検出します。参考画像は一覧で切り替えられます。「対象TXT（全件）」の一覧はファイルの確認用です。一覧で選んだ1件だけでなく、保存開始時にフォルダー直下にある全TXTを切り出します。子フォルダーは検索しません。提示された `43.5C_luminanth.bmp` は内容がPNGですが、そのまま読み込めます。
2. 「拡大 ＋」「縮小 −」またはマウスホイールで表示倍率を変更します。「100%（X方向等倍）」は横方向の1画素を画面の1ピクセルで表示、「全体表示」は画面に収まる倍率です。拡大時はスクロールバーで表示位置を移動できます。倍率を変えても指定した点の元画像座標は維持されます。
3. 「指定する点」で始点、幅方向の終点、高さ方向の点を選び、画像上をクリックします。未指定の点がある場合は次の未指定点に自動で切り替わります。画像上の番号1・2・3が各指定点です。3点目は長方形の高さを決めます。実寸ヘッダーがある場合はmm空間で直角を計算するため、縦横の画素寸法が異なっても表示上の長方形を維持します。保存する座標にも同じ変換を適用します。
4. 修正したい点を「指定する点」で選んでクリックすると、その点だけを変更できます。「指定をクリア」で3点と選択枠をすべて消せます。
5. 「四辺から内側へ」で1～10ピクセルを指定します（初期値1）。赤枠は元の指定範囲、緑枠が実際の保存範囲です。斜めの矩形でも幅・高さの各方向から指定量を除外します。例えば100×80の範囲に5ピクセルを指定すると、四辺から5ピクセルずつ除外して90×70で保存します。画面の拡大率には影響されません。縮めた結果が0以下になる設定では保存できません。
6. 緑枠を確認して「全TXTを保存」を押します。全ファイルを同じ位置・角度・サイズで切り出します。入力フォルダーの下に保存開始日時のフォルダー（例：`RECT_2026_10_01_12_12_12`）を作成し、元のTXTと同じファイル名で保存します。同名フォルダーが既にある場合は `_001`、`_002` の連番を付けます。入力フォルダー直下の `*.tmp` と `*.3m` も元の名前・内容のままコピーします（拡張子の大文字・小文字は区別しません）。
7. 処理中のポップアップに現在のファイル名と件数を表示します。付随ファイルのコピー中も名前を表示します。終了後にTXT処理とコピーそれぞれの成功・失敗件数、保存先を表示します。読み込みできないTXTは記録して次へ進みます。

## 出力

- 元の名前の `*.txt`（例：`1_R43.5C_Measure.txt`）: 各ファイルから切り出したMatrix。1行目の `#WIDTH` と `HEIGHT` は出力画素数に合わせて更新します。
- `Selected_Image.bmp`: 選択した参考画像の切り出し結果（共通の1枚）。
- `Selection.info`: 内側へ縮めた保存範囲の座標、出力寸法、内側に除外したピクセル数（MarginPixels）、サンプリング方法。
- 元の名前の `*.tmp`、`*.3m`: 入力フォルダーからコピーした付随ファイル。
- `BatchResult.log`: TXT処理とコピーの成功件数、失敗したファイル名・理由。

## 高速化

共通の座標対応表と作業メモリを一括処理で再利用し、必要な数値だけを読み取ります。TXTは行単位でまとめて書き込み、参考画像は画像メモリから直接コピーします。OpenCVなど追加ライブラリのインストールは不要です。

今回の環境で、実データ3ファイル・2600×2500画素の斜め切り出しは約13.5秒から約1.4秒に短縮しました。TXT・Bitmap・座標情報は変更前とのSHA-256一致を確認済みです。処理時間は保存先ドライブとデータ量によって変わります。

画素とMatrixは最近傍方式で対応させます。選択範囲が元画像の外側に出た部分は、Matrixは `0`、画像は黒になります。各Matrixには同じ座標を適用し、指定範囲外の行列数の違いや不正値は無視します（例：参考画像が3437画素幅でMatrixが3438列でも処理可能）。座標の拡大縮小や列の削除はしません。指定範囲に必要なデータが欠ける場合や、指定範囲内に整数以外の値がある場合だけ、そのTXTを失敗として記録します。書き込み途中で失敗した場合に残る `.partial` ファイルは未完成データです。

## データ縮小（Y方向）

「データ縮小」タブで入力フォルダーを開き、縮小予定の行数と画素間隔を確認して「全TXTをY方向に縮小して保存」を押します。

- X間隔 = WIDTH ÷ 列数、目標Y行数 = HEIGHT ÷ X間隔を四捨五入した整数です。最低1行、元の行数を上限とし、拡大しません。
- 各TXTのヘッダーと行列数から個別に計算します。WIDTH・HEIGHTとX列数は保持するため、実寸の縦横比は変わりません。整数行数に丸めるためX・Y間隔には僅かな差が残ります。
- Y方向は区間の重なりによる加重平均です。0も含めて平均し、整数へ四捨五入します。細い溝や鋭いピークは平均化されます。
- 直下の全TXTを `REDUCE_yyyy_MM_dd_HH_mm_ss` へ元と同じ名前で保存します。子フォルダーは対象外で、元ファイルは変更しません。同名フォルダーがある場合は連番を付けます。
- 処理中はファイル名を表示します。不正なヘッダー・値・不揃いな列数のファイルは失敗として記録し、次を処理します。詳細は `ReduceResult.log` に記録します。
- 出力フォルダーを開くと、縮小したTXTから位置指定用画像を生成できます。実寸の縦横比で表示し、切り出し・マスクの入力にも使用できます。

## フォルダー履歴

フォルダーを正常に開くと、最後の場所をユーザー別に記憶します。再起動後も全タブのフォルダー選択に適用されます。初回はマイドキュメント\malcom\SRS360を表示します。保存先がなくなった場合も既定に戻り、既定のフォルダー自体がない場合はマイドキュメントを表示します。キャンセル・読み込み失敗では履歴を更新しません。履歴は %LOCALAPPDATA%\MatrixBitmapCrop\LastFolder.txt に保存します。


## 切り出し後の自動表示

全TXTの切り出し完了ダイアログでOKを押すと、成功したTXTがある場合は作成したフォルダーをアプリ内で自動的に開きます。指定に使った画像も同じ座標・内側指定で切り抜き、Selected_Image.bmpとして保存して表示します。切り出し前の選択枠はクリアされ、保存先は最後に開いたフォルダーとして記憶されます。全TXTが失敗した場合は元の表示を保持します。

## 温度補正（Make Correct）

「温度補正」タブに、元ソフトの MakeMatrixDataConvert → ValiableRangeTest → CreateSelectedCorrectedData の処理を移植しました。入力フォルダーを開き、TMPを選択して「Make Correct」を押してください。

- 計測TXTは連番_R（昇温）・連番_C（降温）の名前で、各2件以上が必要です。連番の数値順で読み込みます。
- ヘッダーにはWIDTH/HEIGHTと、スキャンごとのTempS/TempE/TimeS/TimeEが必要です。複数スキャンは元ソフト同様、Y行をスキャン数で分割し端数を最後へ割り当てます。スキャン数がファイル間で異なる場合や不正な数値は処理を中止します。
- TMPの第3列からピーク温度を求めます。複数TMPがあれば選択してください。初期候補はtempData.tmpです。
- 昇温開始・降温終了はTMPと読み込んだMatrixから自動判定します。各スキャンのTempS/TempEの平均温度を使い、全スキャンに共通する範囲と、TMPのピーク前・ピーク後それぞれの温度範囲を重ねて下限を求めます。保存形式に合わせ小数1桁へ範囲内に丸めます。結果はCorrectionResult.logに記録します。「通常の温度刻み」で全域の刻みを変更できます（初期10℃、1～1000℃の整数）。ピーク温度のMatrixは別途1回保存します。固定のピーク付近2℃刻みは廃止し、ピーク前後にも画面の設定を適用します。
- 「指定範囲の温度刻みを有効にする」をONにすると、表の下限℃・上限℃・刻み℃を使います。初期値は150～180℃を2℃刻み、230～244℃を1℃刻みです。セルの編集、範囲の追加・削除ができます。数値は小数1桁まで、下限＜上限、刻みは1℃以上の整数で指定してください。
- 範囲内では通常設定と指定範囲の小さい刻みを採用します。重複する範囲も最小の刻みを使い、範囲境界は設定刻みに合う場合に含めます。OFFでは表の設定を無視して通常刻みのみで処理します。設定内容はCorrectionResult.logへ記録します。設定は今回の起動中に保持され、次回起動時は初期値に戻ります。
- 昇温は自動判定した開始温度を起点、降温はピーク温度を起点として刻みます。補間元のないピーク前後は、通常補間可能な近傍データとピークから補間します。刻みに合わない開始・終了温度の追加保存は行いません。範囲境界・ピーク直前・終了温度直前の間隔は指定刻み未満になる場合があります。
- 通常はスキャンごとに温度を挟む2データを選び、X列の計測温度から補間します。ピークは元ソフトの時間ベースの補間を使用します。補間に必要な組がない通常温度は元処理同様に出力を省略します。列数やスキャン行数に差がある場合は共通部分を使用します。
- 元ファイルは書き換えず、CORRECT_日時フォルダーへ新たな温度の連番_R/Cファイルを保存します。BMP・TMP・3mもコピーし、作成ファイルをCorrectionResult.logへ記録します。既存Correctフォルダーの削除や元データへの上書きは行いません。
- 起動時の入力表示は従来どおりです。補正後の結果を見る場合は作成フォルダーを開いてください。

### 配布と開発環境

温度補正は元ソフトと同じOpenCvSharp/OpenCVを使用します。今回から64ビットWindows用です。Release481またはReleaseVS2017フォルダーをDLLとexe.configごと配置して実行してください。EXEだけのコピーでは動作しません。開発用DLLはlibに含めています。.NET Framework 4.8.1版とVS2017向け.NET Framework 4.7.2版を同梱します。

元ソースの数学処理はCorrection.Core.cs、Correction.NearPeak.cs、Correction.VariableStep.csへ移し、入出力はCorrection.IO.cs、画面はMainForm.Correction.csに分離しています。元のSRS-3ソースは変更していません。検証は合成データによる温度補間・ピーク・降温出力とローカルのOpenCV実行確認です。実際の計測結果との比較は未実施です。
温度列の整列：10℃刻みは50・60・70℃のように10の倍数です。10℃未満は整数温度を起点に並べます（開始50.2℃、5℃刻みなら51・56・61・66℃）。昇温は範囲内へ切り上げ、降温は切り下げます。10℃以上の刻みの起点は十の位へそろえます。ピーク温度のみ実測値を別途保存します。

## 切り出し枠の回転調整
3点を指定した後、切り出しタブの回転角度欄のスピンボタンで枠の中心を固定して回転します。上ボタンは右へ0.1度、下ボタンは左へ0.1度で、刻み幅は固定です。実寸の縦横比に合わせて回転し、保存するデータ・画像にも同じ座標を使用します。出力行列数を保持し、内側指定も回転後の枠へ適用します。

## 切り出し時の0以下の補正

## 位置合わせ（AnalyzeMatrixAlignmentAll）

「位置合わせ」タブで入力フォルダーを開き、基準TXTを選び「全TXTの位置合わせを実行」を押します。左側のパネル幅を330pxへ広げています。

- 初期の基準TXTは、先頭の連番を数値として並べた最初のファイルです。基準は一覧で変更できます。全TXTをそれぞれこの同じ基準へ合わせます。
- 元のAnalyzeMatrixAlignmentAllが呼び出すMatrixAlignmentTwoStepをAlignment.Core.csへ移植しています。1/4縮小＋ガウシアン窓で大まかな移動量を求め、中央50%で精密な移動量を求めます。両方を合成し、元の対象データに1回の線形補間で適用します。整数化は元処理同様の切り捨てです。範囲外は0です。
- 「各Matrixの最小値を0に補正」は元画面同様に初期ONです。各ファイルの全セルからそのファイルの最小値を引きます。OFFでは高さの基準を保持します。
- 入力は8行・8列以上の整数Matrixで、基準と同じ行列数が必要です。異なる行列数、不揃いな列、不正値のファイルは失敗として記録し、次へ進みます。
- ALIGN_日時フォルダーへ元と同じTXT名で保存します。実寸・スキャン温度・時刻など元ヘッダーは保持します。入力ファイルと既存結果は変更しません。
- AlignmentReference.bmpは位置合わせの基準TXTから生成した参考画像です。TMPと3mもコピーします。AlignmentResult.logに各ファイルの移動X/Y（画素）、相関応答、成功・失敗理由を記録します。相関応答は確率ではなく、模様の少ないデータでは位置の推定が不安定になる場合があります。
- 元ソフトで成功表示のresponsが常に0だった箇所は、実際の精密合わせの相関応答を記録する形にしています。基準ファイル自身は不要な変換を行わず保存します。

## 切り出し枠の数値サイズ変更・移動

## 回転角度の直接入力とEnter反映

回転は基準枠から毎回計算し、同じ角度でEnterを押し直しても加算しません。枠の中心・実寸サイズ・保存行列数を保持します。サイズ変更後とドラッグ移動後も現在位置に合わせて回転基準を更新します。3点の再指定と指定のクリアで追加回転角を0に戻します。

## 画像端を近傍値で平らに埋める

マスクタブに「画像端は近傍値で平らに埋める」を追加しました。初期状態はONです。左右端に接するマスクは、同じ行の内側にある最寄りの正常値を端まで同じ値で延長します。上下端だけに接する場合は同じ列の正常値を延長し、四隅では横方向を優先します。これにより、右端のマスク内へ右肩下がりの傾斜を追加しません。行と行の間の実測値の変化は保持します。

全マスク領域・未計測値（0除外ON時）・推定正常面から大きく外れる参照値は使用しません。同じ行・列に正常値が見つからない場合は従来の正常面推定による補間を使用します。内側のマスクは従来の周囲補間を使います。このチェックをOFFにすると画像端も従来の反り推定で補間します。

0点補正は補間後に適用するため、ONでもマスク内の平らな形は保持されます。0点補正OFFではマスク外の数値文字列を変更しません。元のREDUCEフォルダーと同じMaskDefinition.xmlを使って再処理してください。処理済みMASKフォルダーへの重ね掛けは避けてください。

## 画像端の平坦化率を調整

「画像端は近傍値で平らに埋める」を「画像端の傾斜を調整する」に変更し、平坦化率（0～100％、整数）を追加しました。初期値は50％です。従来の反り補間値と近傍値を延長した平らな値を、整数へ丸める前に混ぜます。

- 0％：従来の反り補間。
- 50％：従来の補間結果と平らな結果の中間。
- 100％：近傍値で平らに埋める。
